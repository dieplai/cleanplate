# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique work and not people. Harassment of any kind is not tolerated.
Report problems privately to the maintainer through GitHub (open a minimal issue asking for contact, or use the
maintainer's profile); reports are handled confidentially.
